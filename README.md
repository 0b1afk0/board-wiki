## 📌 2. Модели

### `Tag` (Категория/Тег игры)
| Поле        | Тип               | Описание                          |
|-------------|-------------------|-----------------------------------|
| `name`      | CharField(50)     | Название тега (уникальное)        |

### `Game` (Настольная игра)
| Поле        | Тип               | Описание                          |
|-------------|-------------------|-----------------------------------|
| `title`     | CharField(200)    | Название игры                     |
| `description` | TextField       | Описание игры                     |
| `players`   | CharField(100)    | Количество игроков                |
| `rules`     | TextField         | Правила игры                      |
| `image`     | ImageField        | Изображение игры                  |
| `tags`      | ManyToManyField   | Связь с тегами игры               |

### `Comment` (Комментарий к игре)
| Поле         | Тип               | Описание                          |
|--------------|-------------------|-----------------------------------|
| `game`       | ForeignKey(Game)  | Связь с игрой                     |
| `author`     | CharField(100)    | Автор комментария                 |
| `text`       | TextField         | Текст комментария                 |
| `created_at` | DateTimeField     | Дата создания (автоматически)     |

## 📌 3. Основные страницы (views + urls)

| URL                    | View          | Название маршрута | Описание                          |
|------------------------|---------------|-------------------|-----------------------------------|
| `/`                    | `g_list`      | `g_list`          | Главная страница, список всех игр |
| `/g/<id>/`             | `g_detail`    | `g_detail`        | Страница отдельной игры + форма добавления комментария |
| `*` (все остальные)    | `page_not_found` |                | Кастомная страница 404            |

✅ Главная страница - это список игр, отдельной главной страницы нет.

## 📌 4. Функциональность

### 🔍 Поиск и фильтрация
- Поиск игр по названию в реальном времени
- Фильтрация по тегам через модальное окно
- Поддержка множественного выбора тегов
- Сохранение выбранных фильтров в адресной строке
- При открытии ссылки с параметром `?tags=` фильтр применяется автоматически
- Кнопка сброса фильтров

### 🎮 Страница игры
- Подробная информация об игре, описание и правила
- Кликабельные теги с переходом на отфильтрованный список
- Комментарии пользователей
- Форма добавления комментария с валидацией
- Защита от спама методом Honeypot

### ✅ Валидация комментариев
- Имя: от 2 до 30 символов
- Комментарий: от 5 до 500 символов
- Защита от никнеймов из одинаковых символов
- Защита от никнеймов без букв
- Отображение ошибок с сохранением введенных данных

### 🎨 Дизайн
- Современный дизайн с градиентами
- Полностью адаптивный для мобильных устройств
- Плавные анимации и эффекты
- Кастомная страница ошибки 404

## 📌 5. Шаблоны

❌ `base.html` отсутствует, каждый шаблон самодостаточный.

Шаблоны:
- `templates/g/list.html` - список игр с поиском и фильтрами
- `templates/g/detail.html` - детальная страница игры с комментариями
- `templates/404.html` - страница ошибки 404

Все стили лежат в `templates/css/style.css` и подключаются напрямую в каждом шаблоне.
